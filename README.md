# 🌿 EcoPulse: Environmental Intelligence

EcoPulse is a research-oriented platform for monitoring air quality and weather in Chennai, India. It features a novel **Forecast Trust Engine** that transparently evaluates data quality and detects anomalies.

## 🚀 How to Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
3. Click **"📡 Fetch Live Data"** in the sidebar to initialize the database.

## 🧠 Architecture
- **Backend:** Python, Pandas, Scikit-Learn, SQLite
- **Frontend:** Streamlit, Plotly
